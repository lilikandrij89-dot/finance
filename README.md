# ФІНАНСОВИЙ ШТОРМ: Ринок Активів

Інтерактивний веб-додаток реального часу для підсумкового заняття з теми **«Фінансове планування та прогнозування»** (розділи 3.9.1–3.9.4 + Таблиця 3.4 методів) для групи з 25 студентів (5 команд × 5 осіб).

## 3 синхронізовані екрани
- `/projector` — екран для проєктора (Вітрина активів, живий рейтинг капіталу, таймер, Long/Short ставки, 🎡 Фінансова рулетка, подіум).
- `/play` — мобільний інтерфейс студентів (роль `Капітан + Аналітики`, командне голосування в тестах/кейсах/конструкторах, ставки, Чорний ринок).
- `/admin` — пульт викладача (повна **Шпаргалка** з правильною відповіддю та академічним поясненням із конспекту, керування раундами/таймерами, спецподії, матриця засвоєння тем 3.9.1–3.9.4, експорт звіту в CSV).

---

## Локальний запуск (працює без ключів через вбудований Server-Sent Events Realtime)

```bash
npm install
npm run dev
```

Відкрийте у браузері `http://localhost:3000`. Студенти в одній локальній Wi-Fi мережі можуть підключатися за локальною IP-адресою вашого ноутбука: `http://<IP-ноутбука>:3000/play`.

### Перевірка тестів та збірки
```bash
npm test
npm run build
```

## Хмарний деплой (Vercel + Supabase Realtime)

1. Створіть проєкт у [Supabase](https://supabase.com/) та виконайте SQL-скрипт із файлу `supabase/schema.sql` у **SQL Editor**.
2. Скопіюйте `.env.example` у `.env.local` (або додайте змінні середовища в налаштуваннях проєкту на Vercel):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `NEXT_PUBLIC_ADMIN_PIN` *(необов'язково, для захисту `/admin` паролем)*
3. Задеплойте репозиторій на Vercel — платформа автоматично перемкнеться на **Supabase Postgres + Realtime**.
